1. Variables and Assignment

Variables are containers for storing data values. In Python, you don't need to declare the type of a variable; it is determined automatically based on the value assigned.

Rule: Variable names must start with a letter or underscore, and are case-sensitive (e.g., age and Age are different). 
# This is a comment - Python ignores this
name = "Alice"          # String variable
age = 25                 # Integer variable
is_student = True        # Boolean variable

# Printing the variables
print(name)
print(age)

2. Basic Data Types

Python has several built-in data types used to represent different kinds of information:

  • Int: Whole numbers (e.g., 10, -5)
  • Float: Decimal numbers (e.g., 10.5, 3.14)
  • String: Textual data wrapped in quotes ("Hello")
  • Boolean: Logical values (True or False)
# Demonstrating different types
x = 10               # int
y = 3.14             # float
name = "Python"      # str
is_easy = True       # bool

# Checking the type of a variable
print(type(x))       # Output: <class 'int'>
print(type(name))    # Output: <class 'str'>

3. Control Flow (If/Else & Loops)

Control flow allows your program to make decisions and repeat actions.

Conditional Statements

The if statement executes a block of code only if a specific condition is met.

age = 18

# Simple If/Else
if age >= 18:
    print("You are an adult.")
else:
    print("You are a minor.")

# Using elif for multiple conditions
score = 85
if score >= 90:
    print("Grade: A")
elif score >= 80:
    print("Grade: B")
else:
    print("Grade: C")

4. Loops

Loops are used to repeat a block of code multiple times.

  • For Loop: Used for iterating over a sequence (like a list or range).
  • While Loop: Used to repeat as long as a condition remains True.
# For loop printing numbers 0 to 4
for i in range(5):
    print("Number:", i)

# While loop - runs until condition is False
count = 0
while count < 3:
    print("Count is:", count)
    count += 1

5. Functions

A function is a reusable block of code that only runs when it is called. You define them using the def keyword.

# Defining a function
def greet_user(username):
    return f"Hello, {username}! Welcome to Python."

# Calling the function
message = greet_user("John")
print(message)

# Function with parameters and logic
def add_numbers(a, b):
    return a + b

print(add_numbers(5, 10))

6. Common Data Structures

Python provides powerful built-in types to store collections of data.

Lists

Ordered, changeable collections. Allows duplicate members.

fruits = ["Apple", "Banana", "Cherry"]
fruits.append("Orange")
print(fruits[0]) # Access first item

Dictionaries

Unordered, changeable collections of Key:Value pairs.

user = {
    "name": "Jane",
    "age": 28,
    "city": "New York"
}
print(user["name"]) # Accessing value by key
